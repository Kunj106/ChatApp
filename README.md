Real-Time Chat Application:
A feature-rich, real-time chat application built with Socket.io, supporting instant messaging, group chats, file/image sharing, and user authentication.

Overview:
This is a real-time chat application that allows users to communicate instantly, create group conversations, and share files and images , all powered by WebSockets via Socket.io.
The app is designed to be responsive, scalable, and easy to use.

Features:
• User Authentication — Secure sign-up and login system to protect user accounts.
• Real-Time Messaging — Instant message delivery using WebSocket connections via Socket.io.
• Group Chats — Create and join group conversations with multiple participants.
• File & Image Sharing — Share images and files directly within chat conversations.
• Online/Offline Status — See which users are currently active.
• Message Timestamps — Every message is timestamped for clarity.

Tech Stack:

Real-Time Messaging             Socket.io
Backend                         Java SpringBoot
Frontend                        HTML / CSS / JS
Database                        MySQL
Auth                            JWT / Session-based
